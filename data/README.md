# Data

The data files are not stored in this repository: the original dataset takes about 126 MB, and every processed file can be regenerated by running the notebooks.

## 1. Download the original dataset

**Brazilian E-Commerce Public Dataset by Olist**, published on Kaggle under the CC BY-NC-SA 4.0 license:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Option A, from the browser: sign in to Kaggle, click **Download**, unzip the file and copy the 9 CSV files into `data/raw/`.

Option B, from the terminal, with the [Kaggle API](https://github.com/Kaggle/kaggle-api) installed and configured:

```bash
kaggle datasets download -d olistbr/brazilian-ecommerce -p data/raw --unzip
```

`data/raw/` should end up with these files:

| File | Content |
|---|---|
| `olist_orders_dataset.csv` | Orders, status and dates |
| `olist_order_items_dataset.csv` | Items sold, price and freight |
| `olist_products_dataset.csv` | Product category, size and weight |
| `olist_customers_dataset.csv` | Customer location |
| `olist_geolocation_dataset.csv` | Coordinates by zip code prefix |
| `olist_order_reviews_dataset.csv` | Review scores and comments |
| `olist_order_payments_dataset.csv` | Payment methods and installments |
| `olist_sellers_dataset.csv` | Seller location |
| `product_category_name_translation.csv` | Category names in English |

## 2. Generate the processed data

Run the notebooks in order. Each one writes its outputs to `data/processed/`:

| Notebook | Outputs |
|---|---|
| `01_data_cleaning.ipynb` | `orders_clean.csv`, `items_clean.csv`, `geolocation_clean.csv`, `cleaning_log.csv` and the SQLite database `olist.db` |
| `02_exploratory_analysis.ipynb` | `monthly_sales.csv` |
| `03_products.ipynb` | `product_abc.csv`, `category_summary.csv`, `category_monthly.csv` |
| `04_forecast_inventory.ipynb` | `model_comparison.csv`, `forecast_total.csv`, `forecast_categories.csv` |
| `05_geographic.ipynb` | `state_scores.csv`, `city_summary.csv` |
| `06_customer_churn.ipynb` | `churn_dataset.csv`, `churn_model_metrics.csv`, `customer_return_scores.csv` |

The raw files are never modified: all cleaning happens in `01_data_cleaning.ipynb`.
